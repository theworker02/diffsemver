# diffsemver

Diff CSV/TSV semver tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/diffsemver/

## Install / run

```bash
git clone https://github.com/theworker02/diffsemver.git
cd diffsemver
node src/cli.js
node --test
```
